## About
Sales Dashboard is a modern, interactive data visualization tool designed to help sales teams explore and compare sales performance metrics across regions, products, and time periods.

## Purpose
The Sales Dashboard helps teams track KPIs, identify trends, and make data-driven decisions to optimize sales performance and revenue growth.

## Tech Stack
- **Power BI Desktop** - Main data visualization platform used for report creation
- **Power Query** - Data transformation and cleaning layer for reshaping and preparing the data
- **DAX (Data Analysis Expressions)** - Used for calculated measures, dynamic visuals, and conditional logic
- **Data Modeling** - Relationships established among tables to enable cross-filtering and aggregation
- **File Format** - .pbix for development and .png for dashboard previews

## Data Source
Source: Sales Database & Market Observations.

Data includes 5000+ sales records across 20+ regions, including details on their location, revenue, pipeline, conversion rates, and seasonal trends for each month.
